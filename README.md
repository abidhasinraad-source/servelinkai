# ServeLinkAI — Production B2B Website

> **AI Automation for Home-Service Businesses**  
> Turn more website enquiries into qualified leads — automatically.

A modern, high-performance static website for **ServeLinkAI**, an AI automation agency specializing in 24/7 AI Website Receptionists and lead triage for trade professionals (plumbers, electricians, HVAC, roofing, garage doors, pest control, cleaning, and landscaping).

---

## 🚀 Live Pages Included

The website contains all 9 production-ready pages with matching design, navigation, footer, and responsive behavior:

1. **`index.html`** — High-converting homepage with hero, benefit strip, problem breakdown, 4-step workflow, live interactive demo preview, solutions grid, industries overview, "Why ServeLinkAI", pricing preview, integration cards, use cases, FAQ accordion with JSON-LD schema, and final CTA.
2. **`solutions.html`** — In-depth breakdown of all 6 core services (AI Website Receptionist, Lead Capture & Qualification, Customer Enquiry Automation, Booking & Routing, CRM & Follow-Up, Custom AI Automation).
3. **`industries.html`** — Trade-specific qualification criteria and workflows for 8 major home-service sectors.
4. **`pricing.html`** — Transparent One-Time Setup model (Starter, Growth, Pro) + Optional Monthly Maintenance with full feature comparison table and pricing FAQ.
5. **`about.html`** — Authentic agency mission and operating principles tailored for home-service contractors.
6. **`contact.html`** — Comprehensive lead intake and qualification form ready for Supabase database insertion or webhook dispatch.
7. **`demo.html`** — Multi-trade live interactive demo simulator (Plumbing, Electrical, HVAC) with real-time lead capture cards and a dedicated Voiceflow embed slot.
8. **`privacy.html`** — Privacy policy with clearly marked editable placeholders (`[Insert Business Name]`).
9. **`terms.html`** — Terms & conditions governing automation setup, client responsibilities, and optional maintenance.

## 📦 Supabase Integration & Database Preparation

The contact form is prepared to write directly to a Supabase table named `leads`.

### Supabase Table Schema SQL
Execute the following query in your **Supabase SQL Editor**:

```sql
-- 1. Create the leads table
CREATE TABLE IF NOT EXISTS public.leads (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  business_name TEXT NOT NULL,
  email TEXT NOT NULL,
  phone TEXT NOT NULL,
  website TEXT,
  industry TEXT,
  service TEXT,
  contact_method TEXT DEFAULT 'Email',
  challenge TEXT,
  message TEXT,
  status TEXT DEFAULT 'new',
  created_at TIMESTAMPTZ DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL
);

-- 2. Enable Row Level Security (RLS)
ALTER TABLE public.leads ENABLE ROW LEVEL SECURITY;

-- 3. Create public INSERT-only policy for website visitors
CREATE POLICY "Allow public insert into leads"
ON public.leads
FOR INSERT
TO anon
WITH CHECK (true);
```

### Supabase Storage Preparation
The website supports dynamic image delivery from Supabase Storage via `SupabaseService.getImageUrl()`:
1. Create a public bucket named `website-images` in Supabase Storage.
2. In `js/config.js`, set `supabase.storage.enabled = true` and provide `publicUrlBase`.
3. Any image with `data-storage-key="folder/filename.png"` will automatically resolve to the Supabase Storage URL while falling back safely to local assets.

## ⚡ Voiceflow Embed Preparation

To load a real Voiceflow chatbot on `demo.html` or globally:
1. Open `js/config.js`.
2. Change `voiceflow.enabled` to `true`.
3. Paste your Voiceflow Project ID into `voiceflow.projectID`.
The integration script in `js/demo.js` will automatically load the official widget bundle without touching any HTML files.

## 🔄 Make.com Automation Webhook

If you want inbound leads from the contact form to trigger instant notifications (Slack, WhatsApp, SMS, or CRM) via Make:
1. Create a Custom Webhook in Make.com.
2. In `js/config.js`, set `make.enabled = true` and paste your webhook URL into `make.webhookUrl`.

## 🌐 Deploying to GitHub Pages

1. Push this repository to GitHub.
2. Navigate to your repository **Settings** → **Pages**.
3. Under **Branch**, select `main` (or `master`) and directory `/ (root)`.
4. Click **Save**. Your site will be live immediately at `https://<your-username>.github.io/<repo-name>/`.
5. (Optional) Under **Custom domain**, enter `www.servelinkai.com` and configure your DNS `CNAME` and `A` records.
